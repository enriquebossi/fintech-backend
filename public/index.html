Fintech Backend API

This service exposes several endpoints for interacting with financial data and the Cosmo assistant.

  • POST /api/query-supabase – generate SQL with AI and query your Supabase database.
  • POST /api/chat – ask questions to the Cosmo Triage assistant.
  • GET/POST /api/xibalba-mini – store and retrieve JSON messages.

See the project documentation for setup instructions and more details.
